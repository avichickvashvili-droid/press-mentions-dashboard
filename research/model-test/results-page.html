How long the first 90-day run would take

About 20,000 articles, one at a time on an RTX 4070 Laptop GPU. Daily runs are only a few minutes for any of these models. Running 2 or more at once (planned) should shorten this.

Per company

Where junk slipped through

Share of “relevant” answers that were right, per company. The small number is how many junk headlines the model wrongly let in. Harvey, Astra and Lemonade have confusing names.

Astra tripped up every model: 93 of its 100 results were about other things, mostly OpenAI's new GPT-6 “Astra” model. In the real system the search hint "Astra Space" keeps most of that out before the model ever sees it.

Excluded

Does not fit the system

These models are bigger than the 8 GB of GPU memory. Part of each model has to run on the CPU, which is far slower. gpt-oss:20b was measured before we stopped it: 0.42 articles per second, about 13 hours for the first run.

How we tested

Method and limits

  • The same prompt for every model, a strict JSON answer, temperature 0, and “thinking” turned off.
  • Every model returned valid JSON for all 598 headlines, with no retries needed.
  • The correct answers were written by an AI (Claude) before any model ran, not by a human. A human spot-check is still advised.
  • The model sees only the headline and the publisher. Google News gives no article text.
  • Our original rule, “the fastest model with at least 95% precision”, would pick llama3.2:3b. We recommend qwen3:4b because llama misses 1 in 8 real articles and gets sentiment wrong 4 times in 10.
